# 伴办 · 页面结构与交互说明

| 项目 | 内容 |
| --- | --- |
| 版本 | v0.9.0 MVP |
| 设计基准 | 360 × 780 / 390 × 844 / 430 × 932（iPhone 逻辑分辨率） |
| 导航 | 底部四 Tab + 中央新建按钮；详情页隐藏 Tab，改用底部操作栏 |

## 1. 路由表

| Hash | 页面 | 说明 | 主要入口 |
| --- | --- | --- | --- |
| `#/today` | 今日 | 默认首页 | 底部“今日”、品牌 Logo |
| `#/calendar` | 日历 | 月视图 + 选中日 | 底部“日历” |
| `#/calendar?date=YYYY-MM-DD` | 日历（指定日期） | 深链定位某天 | 外部链接/通知 |
| `#/inbox` | 收件箱 | 全部任务筛选列表 | 底部“收件箱” |
| `#/search` | 搜索筛选 | 全屏搜索 | 今日/收件箱搜索图标 |
| `#/task/:id` | 任务详情 | 单任务全屏 | 任务卡、通知、搜索 |
| `#/settings` | 设置 | 通知/显示/数据/关于 | 底部“设置” |

- 新建/编辑不是路由，是覆盖在页面上的底部弹层（`role="dialog"`），关闭后回到来源页。
- 危险操作确认是独立居中弹层，叠在弹层/页面之上。
- 详情页为沉浸式：隐藏底部 Tab，固定底部“编辑 + 完成”操作栏。
- 从详情返回时优先回到进入前的列表页；从搜索进入详情，再返回仍回到搜索页并保留关键词。

**结构**

1. 头部：品牌、搜索、日期、问候、下一件事、统计条。
2. 智能入口：整块可点，打开新建弹层并聚焦原话输入。
3. 提示区：示例任务、通知权限。两者都可关闭。
4. 焦点卡：最近 48 小时内最近的一件；逾期时整卡转红。
5. 分组列表：已逾期 → 今天 → 接下来 7 天 → 长期任务 → 随时可做。
6. 已完成折叠区：只显示今天完成的任务。

**边界**

- 无任何任务：显示插画式空状态“今天没有安排”。
- 只有无日期任务：显示“随时可做”分组。
- 焦点任务完成/删除：重新计算焦点卡。
- 到达零点：自动更新日期与分组。

**类型差异**

| 类型 | 详情区 |
| --- | --- |
| 限时 | 大倒计时 + 截止进度；逾期红色 |
| 定期 | 大倒计时 + 重复规则；底部“完成本次”；完成后出现“下一次”卡片 |
| 长期 | 目标日倒计时 + 总体进度 + 阶段列表 + 添加阶段 |

**状态**

- 长期阶段：勾选后立即更新总进度；完成全部阶段提示“要结束这个任务吗”。
- 删除：确认弹层；确认后回到进入前的列表或收件箱。

```
│      [一][二][三][四][五][六][日]│
│ 标签 [课程 作业            ]   │
│ 备注 [                     ]   │
│                                │
│ [ 取消 ]        [ 创建任务 ]   │
└────────────────────────────────┘
```

**交互**

- 打开新建：默认无内容，聚焦原话。打开编辑：带原任务数据，聚焦标题。
- 原话输入停顿 650ms 自动解析；识别过程中显示“识别中…”。
- 手动修改任一字段 → 标记“已手动调整”，停止自动覆盖；改原话或点“重新识别”才重新解析。
- 类型切换与重复规则联动：
  - 选“定期”时若无重复，默认每周；
  - 选普通/限时/长期会清空重复；
  - 选重复规则会自动切到定期。
- 选“今晚”会带 20:00。
- 日期留空表示无日期；限时任务保存时会要求补日期；定期任务会自动补今天作为起点。
- 关闭时若有未保存修改，弹出“放弃这次编辑？”确认。
- 保存按钮是表单 submit；回车/移动端键盘“完成”可提交。

## 5. 关键流程

### 5.1 一句话创建

```
点击入口 → 弹层打开 → 输入原话
  → 650ms 防抖 → 本地解析
  → 同步字段 + 显示识别结果
  → 用户确认/修改 → 保存
  → 写 localStorage → 关弹层 → 回到来源页 → Toast
```

异常：

- 没有标题且原话无有效内容 → 不保存，聚焦标题。
- 类型为限时但无日期 → 不保存，聚焦日期。
- 重复规则算不出下一次 → 提示检查星期/日期。
- 存储写入失败 → 保留弹层，提示导出备份。

### 5.2 完成定期任务

```
点击完成
  → 当前任务 status=done, completedAt=now
  → 根据 recurrence + dueAt 计算下一次（严格晚于本次）
  → 克隆新任务（新 id、active、下一次 dueAt、reminders 清空）
  → 当前任务记录 nextTaskId
  → Toast “下一次已生成：…”
```

恢复：

```
恢复当前任务
  → 若 nextTaskId 对应任务仍 active → 删除它
  → 当前任务恢复 active，清空 nextTaskId
```

### 5.3 长期阶段

```
添加阶段（名称/日期/时间）
  → 写入 milestones
  → 重算 progress = done / total
  → 阶段到期前 24h / 到期时提醒
勾选阶段
  → done=true + doneAt
  → 重算进度
  → 全部完成时提示是否结束任务
```

## 6. 空状态与错误状态

| 场景 | 文案/动作 |
| --- | --- |
| 今日无任务 | “今天没有安排” + 记一件事 |
| 日历选中日无任务 | “这一天还是空白” + 添加 |
| 收件箱为空 | “收件箱是空的” + 记一件事 |
| 筛选无结果 | “没有符合条件的任务” + 清除筛选 |
| 搜索无结果 | “没有找到相关任务” + 重置筛选 |
| 任务不存在 | “这个任务不在了” + 返回 |
| 通知被拒 | 设置中说明需到浏览器设置允许 |
| 存储损坏 | 自动备份 `banban.state.v1.broken`，恢复示例 |
| 存储写入失败 | “本地存储空间不足，建议先导出备份” |
| 离线 | 顶部轻提示，功能不受影响 |

## 7. 响应式与可访问性

- 页面宽度 360px 起；360 下表单字段保持单列，类型选择四列不换行。
- 大屏（≥620px）居中显示为 480px 手机壳，不另做桌面布局。
- 底部导航适配 `env(safe-area-inset-bottom)`；详情底栏同理。
- 所有可点元素最小高度 32–48px；主按钮 46–48px。
- 任务类型不只靠颜色：有图标 + 文字。
- 焦点样式：按钮有 `:focus-visible` 描边；输入框用边框 + 外发光，不叠加浏览器默认轮廓。
- 支持 `prefers-reduced-motion` 和设置里的“减少动效”。
- 表单使用真实 `<label>`/`aria-label`；开关使用 `role="switch"`；弹层 `role="dialog"`/`aria-modal`。
